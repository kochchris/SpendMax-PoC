# SpendMax - Proof of Concept (PoC)

## Project Overview
SpendMax is a desktop application that integrates zero-based budgeting with credit card reward optimization. This Proof of Concept (PoC) repository contains the initial, foundational Java code to demonstrate the core setup and development environment for the project. 

## Development Environment
This project was developed and tested in the following environment:
* **Operating System:** macOS / Windows / Linux (Cross-platform)
* **Java Version:** Java SE 25 (JDK 25)
* **IDE:** Compatible with Visual Studio Code, IntelliJ IDEA, Eclipse, or standard command-line compilation.

## Build and Run Instructions
To compile and run this Proof of Concept on your local machine, follow these exact terminal commands:

**1. Clone the repository**
`git clone https://github.com/kochchris/SpendMax-PoC.git`

**2. Navigate into the project directory**
`cd SpendMax-PoC`

**3. Compile the Java code**
`javac Main.java`

**4. Run the compiled program**
`java Main`
